# AI Compass Assessment (Stage 1)

This repository contains the in-progress implementation of the **AI Compass** assessment tool.

## Stage 1 Deliverable

- Static web experience for **Phase 1 – Company Overview** built with vanilla HTML, CSS, and JavaScript.
- Ability to capture company profile details, add departments, and persist data to local storage so that refreshes do not lose progress.
- Phase 2 placeholder unlocked once Phase 1 is saved (full functionality to be delivered in the next stage).

## Getting Started

Open `public/index.html` in a modern browser. All styling and behaviour are self-contained—no build step required.

## Next Steps

Future stages will introduce department-level operational mapping (Phase 2), additional phases, account management views, and the final AI Compass summary report.
